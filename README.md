## 💜 What is Journali?

Journali is a small iPhone app for writing your daily thoughts.
Open it, tap **+**, and write. That's it!
It is built with SwiftUI and follows the MVVM pattern.

---

## ✨ What can you do?

- ✍️ **Write** a new journal with a title and text
- 📝 **Edit** a journal any time by tapping it
- 🗑️ **Delete** a journal by swiping it
- 🔖 **Bookmark** your favorite journals
- 🔀 **Sort** your journals by bookmark or by date
- 🔍 **Search** for any word you wrote
- 💾 **Keep everything saved**, even after closing the app

## 🗂️ Project folders

```
JournalApp
├── Model        → what a journal is
├── View Model   → the app's logic
├── Views        → the screens
├── Components   → small reusable pieces
└── Theme        → colors and fonts
```

---

## ▶️ How to run

1. Download or clone this repo
2. Open `JournalApp.xcodeproj` in Xcode
3. Pick an iPhone simulator
4. Press **▶︎ Run**
